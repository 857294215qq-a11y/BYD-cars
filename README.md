# BYD España · 车型与版本指南

本地入口：双击 `index.html`，用 Safari、Chrome 或 Edge 打开。无需安装依赖或启动服务器。请保留同目录中的 JS、CSS、assets 和 catalog 文件夹；移动时一起移动整个文件夹。

当前范围：西班牙官网导航与配置器上的 13 款车型、32 个版本（19 个纯电、13 个插混版本）。来源页面于 2026-10-12 下载，catalog 核对与网页制作跨 12–13 日。不是实时价格系统。

## 使用

- 菜单分两级：顶部导航为一级（车型 / 续航天梯 / 版本对比 / 学习），悬停或点击展开二级面板。车型面板按纯电、插混列出 13 款车及起价、续航；续航天梯面板分续航、价格、能耗、性能、充电；学习面板分术语讲解、数据口径、官方来源。页面内也有同样的二级标签，网址可直接分享（如 `#model/seal`、`#rank/energy`、`#learn/sources`）。
- 用车成本：拖动每月里程、家充/快充电价、在家充电比例、油价、对比燃油车油耗，所有版本按每月能源费用实时重排，并画出燃油车参考线。插混用电比例可按“每天充满一次”（实际纯电续航按 WLTP 的 85%）自动估算或手动设置。假设保存在本机浏览器。
- 报价单：在版本详情、车型页的版本卡片中点“报价单”，选颜色（自动加价）、填客户和销售顾问，打印或存为 A4 PDF。内容包括价格与促销条件、续航能耗、动力充电、空间、质保、每月能源费用估算和免责声明。销售顾问姓名电话会记在本机，客户姓名不保存。
- 车型页：每款车一页，含起价、续航与动力区间、各版本卡片（逐级列出“相比上一版的变化”）、车身颜色与加价、关键参数表、官方来源与促销到期提醒。

- 车型总览：按动力类型、级别（A00 / A0 / A / B / C）、车身（两厢 / SUV / 三厢 / 旅行车）、车型、版本关键词、价格口径和预算筛选；卡片显示总续航（电 + 油）。
- 快速搜索：Windows / Linux 按 `Ctrl K`，Mac 按 `⌘K`，或任意页面按 `/`；手机点导航栏放大镜。输入车型、版本或“插混 / 纯电 / SUV”，回车直接打开车型页或版本详情。
- 自由对比：添加最多 4 个版本，点击底部“开始对比”。
- 同款比较：点击“比较全部版本”。DOLPHIN G DM-i 可一键看 4 个版本。
- 对比表：勾选“只看差异”，下方逐项配置可以搜索和展开。
- 续航天梯：全部 32 个版本在同一 km 刻度上排队，蓝色为 WLTP 纯电续航，橙色为燃油续航；同一行写明价格、电耗/电池、亏电油耗/加权油耗/油箱、动力、0–100、直流快充。排序方式可选 11 种并可切换升降序，点表头也能排序；按区间分档，未公布的数据放最后。排序切换时行会滑动到新位置。
- 学习与来源：AC/DC、WLTP、kW/kWh、PVP/融资价等中西文解释，官方资料链接和本地 catalog。
- 中文 / ES：切换界面及配置解释。中文模式保留西班牙语原文，便于学习。

## 数据口径与已知差异

- 比较基准是配置器默认配置建议零售价（PVP），不是最低广告价。现金与融资促销只显示官网明确对应的版本，其他版本标为未公布，不按差额推算。
- 促销价格适用西班牙半岛与巴利阿里；活动原文公布有效期至 2026-10-31。可能含融资、补贴预支、CAE 条件，不等于总付款。
- WLTP 综合纯电、城市纯电、插混总续航分开；插混功率为系统功率。CV 根据 kW 换算，标为近似。
- 总续航：纯电车 = 综合纯电续航；插混 = 官方综合总续航。燃油续航 = 总续航 − 纯电续航（推算），与“油箱 ÷ 亏电油耗”相差 3–8%。
- 2026-10-13 补充：按 catalog 技术表补齐油箱容积、WLTP 加权油耗、扭矩、极速、整备质量（DOLPHIN、ATTO 2、SEAL U、TANG、DOLPHIN G DM-i、SEAL 6 / Touring、SEAL U DM-i）。SEAL 6 catalog 的“系统扭矩 122 Nm”实为发动机扭矩，未采用。SEAL U DM-i 加权油耗对比表与 catalog 差异大，已在车型说明中注明。
- 质保取自各车型官网页面：整车 6 年/15 万 km，刀片电池 8 年/25 万 km，电机 8 年/15 万 km（DOLPHIN G DM-i 页面未写电机质保，另写明电池 SOH ≥ 70%）。内饰颜色与轮毂尺寸取自配置器接口，官网未标加价。
- 新增拖挂能力（带/不带制动）、后排放倒后的后备箱容积、车身颜色加价。颜色色块图片引用官网地址，离线时只显示名称与加价。
- 级别为中国市场惯用分级，按车长与定位划分，仅作筛选参考。
- AC 与 DC 最大充电功率分开，时间注明 10–80%、30–80% 或 AC 对应区间与单/三相条件。没有自主推算充电时间。
- 部分当前对比 JSON 的设备值重复错误，已以西班牙官方 catalog 的逐版本设备表为准；部分原文措辞因官网文件不同，统一对比常用项，完整表只对齐同名条目。未公布不等于不提供。
- ATTO 2 DM-i 的当前对比 JSON 与旧 catalog 数字不一致（Boost 115 / 90 km 等），采用当前配置器对比表，保留显著差异提示。购车时核对具体车辆认证。
- SEAL 6 两款 catalog 含 Comfort Lite，但该版本不在当前配置器，未列为当前可选版本。
- TANG 内部 API 别名包含 EV-NL，按西班牙 catalog 展示 Flagship；保留西班牙 API 的 EUR 价格。

## 文件

`data.json`：可读的结构化数据。`data.js`：网页直接加载的数据，无 fetch / 跨域要求。
`catalog/`：13 份官方原始西班牙 PDF（部分官方文件较大，因此文件夹约 700 MB）。
`assets/`：官网下载的车型与版本图片。
`sources/`：官网 HTML、版本 API、对比 JSON、catalog 文字/OCR及提取设备表。
`scripts/build_data.py`：基于已存档资料重建 data.json/data.js；包含人工核对的参数与促销价格。
`scripts/download_sources.py`：重新下载已存档车型名单所指向的公开资料；不是全自动更新器，新增车型/促销变更仍需重新核对。

## 验证

通过 Node 测试验证：空值不作零、排行方向、四版本限制、13/32覆盖、图片/PDF存在、AC/DC与电量区间、官方冲突说明、SURF 升级配置、Comfort 不误配为 Comfort Lite、促销条款数字完整保留。

通过 Codex 内置浏览器验证：桌面和手机视窗、页面渲染、筛选、版本切换、跨车型对比、同款四版本对比、只看差异、配置搜索、双语、展示模式、排行榜和价格条件展开。

内置浏览器的安全策略禁止 file:// 导航，因此实际双击加载未由其自动验证；已验证本机 HTTP 预览，并检查页面的所有运行资源都为本地路径。普通浏览器可以用于双击本地入口。
